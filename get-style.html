2. Legacy HTML Presentation Attributes (No CSS)
Attribute HTML Tag / Usage Effect
bgcolor <body bgcolor="#eef4fc"> Sets page background color without CSS.
font <font color="#0057b8" size="4" face="Arial"> Sets font family, size, and color directly.
align <td align="center"> / <center> Aligns text and layout elements.
border / cellpadding <table border="1" cellpadding="10"> Controls table border width and cell spacing.
